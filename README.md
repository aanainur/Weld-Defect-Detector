Program ini dibuat dengan algoritma CNN dengan perhitungan manual langsung pada program(CNN on scratch), Program hanya menggunakan 1 layer konvolusi, Tujuan utama dari project ini adalah untuk melihat seberapa jauh perbedaan CNN on Scratch dengan algoritma CNN modern.


INDONESIA
1. Buat folder dengan nama train, test, dan valid, kemudian masukkan data citra hasil pengelasan dari berbagai kategori cacat las ke dalam folder yang sesuai sebagai dataset untuk proses pelatihan dan pengujian.

2. Jalankan program latihan.py untuk memulai proses pelatihan CNN. Tunggu hingga proses pelatihan selesai. Setelah selesai, file model hasil pelatihan dengan nama Trained.npz akan dibuat secara otomatis.

3. Jalankan program main.py untuk melihat hasil klasifikasi melalui terminal tanpa antarmuka grafis (GUI). Jika ingin menampilkan hasil klasifikasi menggunakan antarmuka grafis, jalankan program gui.py.

4. Jalankan program inspect_cnn_steps.py apabila ingin melihat tahapan proses kerja algoritma CNN, mulai dari proses preprocessing hingga hasil klasifikasi.


ENGLISH
1. Create folders named train, test, and valid, then place welding images from various weld defect categories into the appropriate folders as the dataset for the training and testing processes.

2. Run the latihan.py program to start the CNN training process. Wait until the training process is complete. Once completed, a trained model file named Trained.npz will be generated automatically.

3. Run the main.py program to view the classification results through the terminal without a graphical user interface (GUI). If you want to display the classification results using a graphical interface, run the gui.py program.

4. Run the inspect_cnn_steps.py program if you want to view the processing stages of the CNN algorithm, from preprocessing to the final classification results.
